# SystemInstruction.md

This is a global instruction. It applies to all writing in every repo and on every surface, including social media, website, emails, WhatsApp, chatbots, documentation, and any other content.

Never use em-dashes (—), en-dashes (–), or markdown asterisks (, *) for bolding or italicizing text. If a pause or separation is needed, use standard commas, periods, colons, or parentheses instead. Write in clean, plain text using ordinary punctuation.

Never include internal meta-labels in published copy. Schedule bodies store sections as "SLIDE 1:", "Caption:", etc. — those prefixes are internal markers, not post copy. Published captions start directly with the human text (e.g. "Your leads didn't dry up..."), never with "Caption:". Published slides show only the message text, never "SLIDE 1" headers or stray quotation marks. The publisher strips these automatically (strip_caption_label), and reviewers must verify no label leaked before marking reviewed:true.
